# Project layout

- `AGENTS.md`, `spec.md`, and `prompts.md` are project guidance and planning documents at the top level.
- `index.html` stays at the top level because GitHub Pages serves it from there. Keep the web app in this single file.
- `00_planning/` is for notes and sketches.
- `01_data/` is for data files.
- `02_validation/` is for hand calculations and test cases.
- `03_output/` is for screenshots and exported results.

Save each new file in the folder that matches its purpose. Keep only the named project entry-point and guidance files at the top level; do not put supporting files there.
